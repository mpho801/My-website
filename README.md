# Bloomsoft Skincare Website

A simple multi-page skincare website built with **HTML** and **CSS**.

## File structure
```text
wede/
  index.html
  README.md
  
  Assests/
    (images used by the pages)
  
  CSS/
    style.css
  
  JS/
    app.js
  
  pages/
    about.html
    enquiry.html
    services.html
    contact.html
```

## Pages
- `index.html` (Home)
- `about.html` (About Us)
- `services.html` (Services)
- `enquiry.html` (Enquiry form)
- `contact.html` (Contact)


## Styling
- Shared stylesheet: `style.css`

## Changelog
- Added `wede/CSS/style.css` with a skincare-themed animated UI (glowing animated gradient background + floating “serum bubbles”).
- Added entrance animations (rise-in) for header/sections/cards.
- Improved responsive layout (including better fitting of the Contact section on small screens).
- Restyled enquiry/contact forms (rounded translucent inputs, focus glow, gradient pill submit button).
- Updated navigation so users can move between all pages using correct relative paths (from `index.html` to every page under `/pages/`).
