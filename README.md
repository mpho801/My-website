# Bloomsoft Skincare Website

A simple multi-page skincare website built with **HTML** and **CSS**.

## Pages
- `index.html` (Home)
- `about.html` (About Us)
- `services.html` (Services)
- `enquiry.html` (Enquiry form)
- `contact.html` (Contact)

## Styling
- Shared stylesheet: `style.css`

## Setup
1. Open `index.html` in your browser.
2. Or serve the folder using any local static server.
